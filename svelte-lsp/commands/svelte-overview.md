Analyze the Svelte project structure.

1. Find all `.svelte` files and organize by directory (routes, lib, components)
2. Identify the routing structure (SvelteKit routes in `src/routes/`)
3. List key lib components in `src/lib/`
4. Check `svelte.config.js` for configuration details
5. Present a concise summary:
   - Project structure (directories and their purpose)
   - Route layout
   - Key components and their props
   - Configuration highlights
